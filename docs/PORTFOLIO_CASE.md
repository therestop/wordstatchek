# WORDSTATCHEK — массовая проверка фраз в Yandex Wordstat

## Коротко

Прикладной инструмент для пакетной обработки списков ключевых фраз. Проект вырос из фриланс-заказа в воспроизводимый open-source продукт с двумя клиентами: C# WPF для Windows и Python CLI для автоматизации.

## Задача

Проверять большие TXT-списки и не терять уже выполненную работу при лимитах API, сбоях сети или ручной остановке. Результ должен быть удобен и для ручного анализа, и для дальнейшей автоматизации.

## Что сделано

- Нативный GUI на C# / WPF и single-file `WORDSTATCHEK.exe`.
- Python CLI с параметрами региона, типа устройства, задержки и числа попыток.
- Интеграция с актуальным Yandex Wordstat API `GetTop`.
- Checkpoint после каждой фразы и безопасное продолжение.
- Retry/backoff для лимитов и временных сбоев.
- Excel, CSV, TXT и JSONL-журнал.
- Автотесты для обеих реализаций и GitHub Actions.
